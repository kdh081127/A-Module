# GIFTS:Mall A-Module 프론트엔드 구현

## 프로젝트 개요
GIFTS:Mall 쇼핑센터의 A-Module(프론트엔드) 구현

## 파일 구조

### HTML 파일
- **index.html** - 메인 페이지 (홈)
- **about.html** - 소개 페이지
- **product-all.html** - 전체상품 페이지
- **product-popular.html** - 인기상품 페이지
- **cart.html** - 장바구니 페이지

### CSS & 스타일
- **style.css** - 전체 스타일시트 (반응형 디자인 포함)

### 이미지
- **logo.svg** - GIFTS:Mall 심벌로고
- **images/** - 상품 이미지 폴더
  - 건강식품/
  - 디지털/
  - 팬시/
  - 향수/
  - 헤어케어/

### 유틸리티
- **generate_images.py** - 상품 이미지 자동 생성 스크립트
- **create_design_mockups.py** - 디자인 시안 이미지 생성 스크립트

## 주요 기능

### 1. 로딩 애니메이션
- 3.5초 지속
- 페이지 초기 로드 및 F5 새로고침 시 표시

### 2. 헤더 및 네비게이션
- 고정형 헤더 (sticky header)
- 메인메뉴 호버 효과
- 서브메뉴 슬라이딩 애니메이션
- 유틸 메뉴 (로그인, 회원가입, 장바구니, 관리자)

### 3. 비주얼 슬라이더
- 3개 이미지 자동 슬라이드 (3초 간격)
- 좌/우 네비게이션 버튼
- 슬라이드 인디케이터 도트
- 마우스 호버 시 자동 재생 정지

### 4. 콘텐츠 섹션
- **판매상품**: 카테고리별 3개씩 상품 표시
- **공지사항**: 6개씩 페이지 분할 (페이지네이션)
- **상품입점/제휴문의**: 배너 4개 + 입점절차 안내 (6단계)

### 5. 푸터
- 로고 및 SNS 아이콘
- 고객센터 정보
- 회사 정보
- 저작권 표시

### 6. 서브페이지
- 일관된 디자인 콘셉트 유지
- 페이지별 제목 및 설명
- 상품 액션 버튼 (장바구니담기, 구매하기)

## 반응형 디자인

### PC 버전 (기본)
- 최대 너비: 1200px
- 정상 표시

### 모바일 버전 (480px 이하)
- 단열 레이아웃
- 축소된 폰트 및 패딩
- 터치 친화적 버튼 크기
- 유연한 그리드 레이아웃

## 사용 기술

- **HTML5** - W3C 표준 준수
- **CSS3** - 반응형 디자인, 애니메이션
- **jQuery** - DOM 조작 및 이벤트 처리
- **Bootstrap 4.3.1** - 레이아웃 및 컴포넌트
- **Font Awesome** - 아이콘

## 접근성 (Accessibility)

- 모든 이미지에 alt, title 속성 포함
- 의미있는 HTML 마크업
- 명확한 링크 텍스트
- 적절한 색상 대비

## 코드 규칙

- **주석**: 한글로 된 명확한 설명 주석
- **들여쓰기**: 4칸 공백
- **네이밍**: 케밥-케이스 (kebab-case) CSS 클래스명
- **세미콜론**: 모든 CSS 규칙에 세미콜론 추가

## 브라우저 호환성

- Google Chrome (최적화)
- 최신 버전 웹브라우저 지원

## 실행 방법

1. A-Module 폴더를 웹 서버의 루트 디렉토리에 배치
2. Chrome 브라우저에서 index.html 열기
3. 또는 로컬 웹 서버 실행:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # 또는 Python 2
   python -m SimpleHTTPServer 8000
   ```
   
   그 후 `http://localhost:8000`에서 접근

## 주요 CSS 클래스

- `.header-fixed` - 고정형 헤더
- `.visual-slide` - 슬라이드 요소
- `.visual-slide.active` - 활성 슬라이드
- `.product-grid` - 상품 그리드 레이아웃
- `.product-card` - 상품 카드
- `.notice-item` - 공지사항 항목
- `.subpage-header` - 서브페이지 헤더
- `.cart-container` - 장바구니 컨테이너
